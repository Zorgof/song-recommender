# Song Recommender — frontend

React + TypeScript single-page app built with Vite. See the [root README](../README.md) and
[docs/implementation-plan.md](../docs/implementation-plan.md).

## Development

Requires Node.js 24 LTS (see `.nvmrc`).

```bash
npm install
npm run dev            # dev server on http://localhost:5173, proxies /api to http://localhost:8000
npm run build          # type check + production build into dist/
npm run lint           # oxlint
npm run format         # prettier --write
npm run format:check   # prettier --check
```
